# Ask AMAN HR

A Retrieval-Augmented Generation (RAG) system for HR queries.

## Project Structure

- `src/`: Source code
  - `ingestion/`: Data loading and document processing logic
  - `embeddings/`: Embeddings generation logic
  - `retrieval/`: Document retrieval and search logic
  - `generation/`: LLM generation and prompting logic
  - `pipelines/`: End-to-end orchestration pipelines
- `evaluation/`: RAG evaluation logic and test datasets
- `data/`: Raw and processed documents
